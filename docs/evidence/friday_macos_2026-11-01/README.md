# CICIDS2017 Friday evaluation — macOS evidence (1 Nov 2026)

Produced on macOS 26.7.1 (arm64) from the evaluation version, commit `09d6269`, Release build,
system libpcap. These files are copied from `results/friday/` (git-ignored) so that the reported numbers can be
traced from the repository. The large per-window traces (`*.trace.csv`, `*.windows.csv`) are not included; they are
regenerated by the command below.

## Inputs

| Input | Identity |
|---|---|
| UNB `Friday-WorkingHours.pcap` (distributed as pcapng) | MD5 `7366c552425956e610bd69f57feb7e7a` (matches the official `.md5`), 8,839,309,056 bytes |
| Converted with `editcap -F pcap` | SHA-256 `9e8de447f9604d4f662cbcac9976266cf7a14d37933ac1e061c92a2a206e4c0a`, 9,997,874 packets |
| Engelen et al. corrected labels (WTMC 2021 release), `Friday-WorkingHours.csv` | SHA-256 `8bf5a79222d2a553b75fe1ee81cc3ddff89b87befaef52e62368fdb2e3a79def`, 547,915 flows |

## Command

```bash
WITH_SENSITIVITY=1 bash tools/eval/run_friday.sh Friday-WorkingHours.classic.pcap Friday-WorkingHours.csv \
    ../r0-ref/build/netsentinel results/friday
python3 docs/evidence/friday_macos_2026-11-01/diag_friday.py results/friday > diagnostics.txt
```

## Files

| File | Content |
|---|---|
| `summary.md`, `metrics.json` | All metrics for r0_raw, b0, b1_nofloor, b1_floor, frozen, b1_floor_r12 |
| `offset.json`, `align.txt` | Measured label-to-capture offset: −7199.501 s, 6,412 matches in one cluster |
| `capinfos.txt`, `pcap.sha256`, `labels.sha256`, `labels_header.txt` | Input identity and format |
| `environment.txt`, `linkage.txt`, `git_describe.txt` | Machine, binary hashes, libpcap, code version |
| `footers.txt` | Trace and window-label footers of the b0 run (counters, coverage, window classes) |
| `run_friday.log` | Full log of the run |
| `diagnostics.txt`, `diag_friday.py` | Read-only analysis of the traces (feature triggers, false-positive structure, DDoS z-scores) and the script that produced it |
| `EVIDENCE_NOTES.txt` | Running notes, including the hypotheses written before any result |

**Redaction (3 Nov 2026):** before the repository was made public, the local macOS account name in absolute paths
(`/Users/<account>/…`) and in the file-owner column of `run_friday.log` was replaced with `REDACTED` in `capinfos.txt`,
`environment.txt`, `footers.txt`, `labels.sha256`, `metrics.json`, `pcap.sha256`, `run_friday.log` and `summary.md`.
Nothing else was changed: every count, metric, timing and hash is as produced. The SHA-256 values identify the file
contents, not their paths, so they remain checkable. The unredacted files remain in the earlier git history.

Every derived metric in `metrics.json` (precision, recall, F1, FPR, false alarms per hour) was recomputed from its
TP/FP/FN/TN counts with no mismatches. Scope: one day of one dataset, window-level metrics; see
`docs/EVALUATION_METHODOLOGY.md` for the mapping rules and their limits.
